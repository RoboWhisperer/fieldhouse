# Scorekeeper phone remote

A second person can keep the score and clock from a phone, so the person running the video can focus on cameras.

> **Built, not yet tried on a physical phone.** Pairing, the code limits and the second network listener were checked with automated tests and real network connections on a computer. Safari and iOS have not been verified. Try it with your own phone before game night.

## Pair a phone

1. Phone and laptop on the same Wi-Fi. The gym's guest Wi-Fi sometimes blocks devices from seeing each other; a school staff network or a small travel router you bring may be needed.
2. On the laptop, open **Settings, Remote**. A QR code and a short code appear.
3. On the phone, scan the QR code with the camera, or open the address shown and type the code.
4. A "Phone remote connected" chip appears on the **Live** screen.

## What the remote can do

- Start and stop the game clock (the biggest button)
- Add 1, 2 or 3 points to either team
- Fouls and timeouts, change the period
- Undo the last change

## What it cannot do

- No video; it shows no camera pictures
- It cannot start or stop the broadcast, cut cameras, fire sponsors or change settings
- It cannot see stream keys

If both the console and the phone change the score, the last change wins and a "Console changed score" message appears.

## LAN safety

- The phone connects through a separate listener that exists only when you turn it on in **Settings, Remote**. Turn it off after the game if you like. Pairing codes are limited in how often they can be tried, and each paired phone gets its own token.

- By default Fieldhouse answers only on the laptop itself. Settings, Remote can limit pairing to the local network ("lock to LAN") and require a code. Keep "require code" on.
- Anyone on the same Wi-Fi who has the code can control your scoreboard. Do not share the code in public chat or on screen.
- Do not forward ports on a router or put the laptop on the open internet.
- Change the code between games if you can.
- If the phone disconnects, the buttons turn off and it retries by itself.
