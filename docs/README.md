# Fieldhouse user guide

Plain-language help for the person who runs the broadcast: a teacher, athletic director, booster-club parent or student crew member. No technical background needed.

Fieldhouse is free and open source. There is no account, no trial and no license key.

> **Beta.** Fieldhouse has been tested with real OBS on Linux. It has not been verified on Windows or macOS, with real USB cameras, with real YouTube or Facebook streaming, or on a physical phone. Boxes like this one mark those places. See the "Known limitations" section of the [main README](../README.md#known-limitations).

## Start here

1. [Getting started](getting-started.md): install, first run, your first broadcast in about 15 minutes.
