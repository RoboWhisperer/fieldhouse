# Game night checklist

Print this page from your browser (Print, then Save as PDF or choose a printer). Tick each box.

Game: ______________________  Date: ____________  Operator: ______________________

## Before tip-off (arrive 60 minutes early)

- [ ] Laptop plugged into power (not on battery)
- [ ] Laptop set to never sleep
- [ ] Cameras on tripods, powered, cables taped down
- [ ] Fieldhouse open (it starts the video engine by itself)
- [ ] **Home**: press **Start game night**
- [ ] **Setup**: teams, colors, rosters correct (spell-check the names)
- [ ] **Setup**: each camera shows a picture in its slot
- [ ] Microphone or crowd sound moving in the audio meters
- [ ] **Check** screen: every row green, or yellow rows understood
- [ ] Free disk space shown on Check is enough for the whole game
- [ ] Stream destination tested (private test stream if your site offers one)
- [ ] Scorekeeper phone paired (if used) and a test point scored
- [ ] Do you have permission to stream this game? (see "Streaming rights")
- [ ] Backup: a phone recording from the stands, charged

## During the game

- [ ] Press **Start broadcast** a few minutes early
- [ ] Watch the status area: stream, recording, disk
- [ ] Check the clock against the scoreboard at the first stoppage
- [ ] Press **Mark moment** for big plays
- [ ] Sponsor message offered at timeouts: press Fire, Skip or Delay
- [ ] If a camera drops: the slate shows; unplug and replug the camera
- [ ] If the app closes: reopen it; a "We restored your game" banner appears. Check the clock

## After the game

- [ ] Press and hold **End broadcast** (1.5 seconds)
- [ ] **Wrap-up**: confirm the recording file exists and plays
- [ ] Export highlights if wanted
- [ ] Copy recordings to a second drive or cloud folder
- [ ] **Reports**: export the sponsor report if needed
- [ ] Free space on the laptop if disk is low
- [ ] Charge camera batteries and phones

If something broke: **Settings, Diagnostics, Export diagnostics bundle**, read it, and attach it to a bug report.
